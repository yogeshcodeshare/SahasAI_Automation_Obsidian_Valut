# SOP → Automation → AI (the progression)

The trainer's whiteboard model, and the spine the whole WhatsApp course is built on. Drawn by hand rather than spoken, so it does not appear in any transcript of the class.

```
SOP  →  Automation  →  AI
           Predictable
           Defined
```

## Reading it

Left to right is both the **order of work** and the **order of maturity**.

1. **SOP** — the written, manual process, understood by a human first. → [[whatsapp-lead-sop-8-stage]]
2. **Automation** — inherits the two properties written beneath it on the board: **predictable** and **defined**. It does exactly what you configured, every time, and will not improvise.
3. **AI** — added last, and only where the first two cannot reach.

## Why the order is not negotiable

- You cannot automate a process you have not written down as an SOP.
- You cannot sensibly apply AI to a process you have not first tried to automate — you would not yet know which parts genuinely need judgement and which were merely undocumented.

Each arrow depends on the box before it. The trainer repeatedly refuses to start at AI for this reason.

## When to reach for AI anyway

Automation's determinism is a feature: use it wherever a wrong answer costs something — pricing, commitments, confirmations. AI carries roughly **2–10% response variability** in exchange for handling what you cannot enumerate in advance.

The deciding question: **do you know every possible input?** If yes, automate. If no — an open-ended chatbot fielding whatever a customer types — use AI.

## Where this matters commercially

It is a sequencing argument to use in a sales conversation. A client asking for "an AI chatbot" on day one usually has no SOP, which means there is nothing to automate and nothing for the AI to be measured against. Selling the SOP and automation first is not upselling — it is the only order that works.
