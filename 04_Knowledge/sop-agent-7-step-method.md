# SOP Agent — 7-Step Method (Automation Saathi)

Client-onboarding framework from the training. Run per new client; adapt to our stack ([[ai-tools-stack-3-layer]]).

1. **Understand the business** — category; lead intake; delivery; tasks/docs; follow-up & payment tracking.
2. **Risk Control Matrix** — Process | Sub-process | Risk | Control objective | Automation solution (tool-wise).
3. **Masters** — static reference tables → [[crm-and-field-model]].
4. **Modules** — dynamic flows between masters → module SOPs.
5. **Reports** — Report | Description | Key fields/filters | Source.
6. **Data-collection checklists** — client-fill forms → [[client-onboarding-brief]], [[agency-intake-form]], [[coaching-intake-form]].
7. **SOP per module** — numbered Trigger → tool step → Outcome; use only the stack tools.
