# Meta Business Verification Notes

For the Sahas AI Meta Business portfolio (WhatsApp setup, via Veblika). Submitted with sahasai.in website.

## Timeline
Meta's own message says ~2 working days. Realistic: **1–5 business days typical**, up to 10–15 in busy periods; official window "10 min – 14 working days". The "2 hours" Veblika mentioned was NOT for full business verification (probably the WhatsApp number step). Don't worry until ~14 days, then file a Meta support request.

## Checking status
Business verification is **binary** (In review → Verified/Not verified) — no step-by-step tracker. Security Centre shows completed items green; you get an email when done.

## Important: WhatsApp can start before full verification
The number can often be connected and start sending (lower limits) while verification is "In review." Full verification unlocks higher limits + green badge. Ask Veblika: "can we connect the number and start now?"

## Optional while waiting (not blockers)
Add sahasai.in as a trusted domain (Peer Approval → Domain security → Add domain); enable passkey/2FA.
