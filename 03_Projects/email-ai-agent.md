# Email AI Agent

An n8n agent inside a busy person's Gmail: every email sorted into **one clear label**, important ones sent to the phone with a **2-line summary**, **replies drafted and waiting**, **fake emails flagged**. The person only checks and sends.

**Audience:** busy founders, CEOs, senior managers and senior professionals working in Gmail (not CA firms — dropped 2026-10-08).
**Status (2026-10-09):** design done, problem statements approved, both PDFs made; build Step 1 done (Google test user). Resume at Setup workflow Steps 2–3.

## Design (approved)
Gmail trigger → clean & check (dedupe, VIP check, strip HTML, trim, mask ID/bank numbers) → **sorting AI with no tools** (label, confidence, needs-reply, High/Normal priority, due date, suspicious, summary) → confidence < 0.75 → Needs Review → apply label → route:
- **Reply Needed** → AI draft in the thread (uses the owner's Facts doc, tone, signature); phone alert only if High or VIP
- **Deadline & Legal** → due date + instant alert, no AI draft
- **Suspicious** → warning alert, never answered
- everything else → labelled; noise moved out of the inbox
→ one log row per email. Side workflows: Setup (create labels, sort last 10 then 50 emails), morning digest (v2), error alert.

Labels and VIP list: [[decision-email-agent-11-labels-and-vip-list]]. Drafts-only rule: [[decision-email-agent-drafts-only]].

## Choices
Telegram alerts in v1 (WhatsApp/Veblika later) · English replies in v1 · Facts Google Doc for reply content · cheap model to sort, Claude to draft · test on Yogesh's own Gmail (existing n8n credential), start with 10 emails.

## Roadmap
v1 sort + label + drafts + alerts + log · v2 morning digest, follow-up drafts, summaries · v3 meeting replies with real free calendar slots · later Hindi/Marathi, WhatsApp, shared inboxes, multi-client.
