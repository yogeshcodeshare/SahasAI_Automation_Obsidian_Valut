# Pricing Ladder (tier-3 Karad; validate on first 3 sales calls)

Core margin lesson: never resell software above vendor cost. Own-stack (GMB Sarathi + n8n + WhatsApp Cloud API) ≈ ₹0/mo → ~90–98% margins. Use paid SaaS (GHL/Veblika) only via the cheap Bizautomation reseller route, or have the client pay the BSP directly.

| Service | Price | Notes |
|---|---|---|
| GMB Boost (audit + optimize + reviews + posts + report) | ₹2,999/mo | ~98% margin |
| WhatsApp Automation | ₹2,999/mo + ₹4,999 setup | ~90% margin |
| Both together | ₹4,999/mo | |
| Reach/Content package (+6–8 reels/mo + boosting) | ₹5,999/mo | high-value verticals (clinics/coaching) |
| Custom automation (per workflow) | ₹8,000–15,000 one-time or ₹1,500/mo | sell the outcome, never "n8n" |
| Annual | 10 months' price for 12 (e.g. ₹29,999/yr) | 15–20% discount; NOT 58% |

## Vertical-specific
- **Coaching classes** = best vertical (one admission = ₹25k–1L). Charge more: "Admission Machine" ₹4,999/mo, or "Season Sprint" ₹19,999 (Feb–June) + ₹1,999/mo off-season. Bill in their cash-flow rhythm. See [[coaching-class-vertical-playbook]].

## GST note
Because the agency runs on an already-registered GSTIN, **18% GST applies from the first rupee** (no ₹20L threshold cushion). Most Karad clients are unregistered → can't claim ITC → price inclusive or explain. See [[gst-legal-structure]].
