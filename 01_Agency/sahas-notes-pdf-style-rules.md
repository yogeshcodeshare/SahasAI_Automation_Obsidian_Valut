# Sahas AI Notes-PDF Style Rules

Yogesh approved these rules one change at a time for Sahas AI notes and carousels. They are implemented
in [[notebook-notes-pdf-skill]].

## Fonts
- **Kalam:** titles, subtitles, headings, box titles, underlined keywords, circled words, callout statements.
- **Patrick Hand:** only normal paragraph, list and description text.

## Colour
- **Light mode (default):** plain off-white paper with **no grid lines**. Red body text, navy ✱ underlined headings, black bold underlined keywords, green only for the conclusion.
  - Yogesh tried charcoal body text and **rejected** it as "too much black". He also dislikes red text inside tables and flows.
  - Rule: **no red text inside tables or flow diagrams**; those use dark ink.
- **Dark mode:** dark brown `#1B1714` on every page. **Gold `#E0A843` replaces red** and **cream `#F3EEDB` replaces black**. Never red on brown. Yogesh especially likes this mode.

## Colour and icon restraint
- Colour boxes and icons go only at the 2–3 most important spots per page. Normal text and ordinary bullet lists stay plain.
- **Icons only in:**
  - colour-coded flow step boxes (brand logos like WhatsApp/Instagram, or colour emoji)
  - circled callouts (e.g. 📞 Voice AI)
- **No icons on:** tip/note/warning boxes, table headers or comparison-box titles. Those get colour and a highlighted label only.
- Each icon must carry meaning and not repeat. Yogesh's reason: icons everywhere look unprofessional.

## Page structure
- **Cover:** centred, with the stacked logo, title and a full-width wave.
- **Inner pages:** a brown horizontal-logo badge top-right, in a rounded yellow box with a curled corner.
- **Last page:** a dark thank-you page with the cream stacked logo, the round seal and the full agency name.
- Logo usage details: [[sahas-ai-logo-direction]].
